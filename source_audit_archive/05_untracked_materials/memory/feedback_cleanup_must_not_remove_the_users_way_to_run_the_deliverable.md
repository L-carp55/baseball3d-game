検証のために足した**起動設定（launch.json 等）を、片付けとして毎回消してはいけない**。消してよいのは自分が散らかした一時ファイルだけで、**ユーザーが成果物を動かすための設定は成果物の一部**。

2026-08-04の野球ゲームで実害。検証のたびに `.claude/launch.json` へプレビュー用のエントリを足し、終わりに毎回消していた（設定を汚さないつもりだった）。6回繰り返した後、ユーザーから「プレビューできません どうしてでしょうか？」と言われた。**プレビューする手段ごと私が消していた**。

**How to apply:**
1. 片付けの対象は「自分が作った一時ファイル・一時的な状態」だけ。**ユーザーが繰り返し使う設定は残す**（継続中のプロジェクトの起動設定は常設にする）
2. 一時的に足したものを消す前に「これはユーザーが次に使うか？」を1問自問する
3. 成果物を渡す時は**動かし方も一緒に渡す**。ローカルサーバーが要らない成果物（外部読み込みの無い単一HTML等）なら、その事実と直接開く方法を伝える。私の作業状況に依存しない経路を必ず1つ残す
4. 設定ファイルの追記が気になるなら、消すのではなく**足したことを伝える**
